# StrictColdCal IEEE manuscript

This directory contains the submission-style source derived from
`project/New_IEEEtran_how-to.tex`.

- `manuscript.tex`: IEEEtran journal manuscript.
- `manuscript.pdf`: compiled six-page submission-style manuscript.
- `references.bib`: cited DTA, dataset, cold-start, and conformal references.
- `evidence_summary.json`: generated from 15 persisted job reports.
- `primary_per_seed.csv`: paper-facing primary metrics.

The manuscript is intentionally bounded to the observed local-CPU Davis pilot.
KIBA and Metz are listed as materialized data only and are never described as
executed results.
