# Download Data Agent

该 Agent 从论文 manifest 和检索结果定位数据集。自动下载必须同时满足许可白名单、官方许可
URL、许可摘录、已知体积、安全格式、公网 URL 和内容校验。ZIP 还会检查路径穿越、符号链接、
加密成员、异常压缩比和成员类型。其他候选统一标记为 `requires_review`。

不超过 10 GiB 的合格数据会同时保存原始下载包到 `raw/`，并把可直接使用的数据本体安全落地到
`datasets/<dataset_id>/<task_token>/`。预计超过 10 GiB 时不在本机下载，只在 `scripts/` 生成
服务器 Shell 脚本并等待用户执行。产物只写入 `data/<project_slug>/`；模型不能扩大许可或目录权限。
每个已下载数据集必须记录压缩/解压字节、行列数、唯一化合物/靶点/配对、缺失率、关键字段
覆盖率及逐测量类型标签统计。页面或论文中的规模只保存为预估值，本地 Profile 是后续代码的
唯一规模依据。`downloaded` 状态必须同时具有原始包和已落地数据文件；ZIP 与 7z 都执行成员
数量、路径穿越、符号链接、扩展名、10 GiB 解压上限和压缩比检查。
